## 📌 Project Overview

**MovieIQ** is an end-to-end data analytics and machine learning project designed to analyze movie data, identify factors associated with movie success, statistically test important relationships, and predict movie success using a **Random Forest classification model**.

The project combines:

- Exploratory Data Analysis (EDA)
- Data Visualization
- Statistical Testing
- Feature Engineering
- Predictive Modeling
- Model Evaluation
- Interactive Streamlit Dashboard

The final result is an interactive analytics platform that transforms movie data into actionable insights.

---

## 🎯 Project Objectives

The main objectives of MovieIQ are:

- Analyze the characteristics of movies and their financial performance.
- Identify patterns associated with movie success.
- Explore relationships between budget, revenue, popularity, runtime, genres, and audience ratings.
- Perform statistical testing to determine whether observed relationships are statistically significant.
- Build a Random Forest model to classify movie success.
- Evaluate the performance of the predictive model.
- Provide an interactive dashboard for exploring the analysis and making movie success predictions.
